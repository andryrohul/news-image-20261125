The Wednesday Ledger: a newspaper front page drawn entirely in code that sums up the world news of Wednesday 25 November 2026 in one 1024x1024 image — 31 stories across 6 regions, led by the US proposal for new tariffs on 14 trading partners (China highest at a proposed 20%), the Cairo Ring Road fuel-tanker fire and Shenzhou-24 docking at Tiangong with the first Pakistani astronaut. Every story carries a CONFIRMED / REPORTED / CLAIM / FORECAST label, with a UTC timeline and a date-check box excluding stories that belong to another day. The program is Python 3.13 standard library only: it renders the page with its own glyph font and vector scenes and writes a deterministic PNG.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
